# yamaken-seo-contents-member

## 開始時：必ず最新版を取得する

このスキルはローダーであり、制作ルール本体を同梱しない。**毎回の新規実行時に**以下の公開GitHubリポジトリの `main` の最新コミットを確定し、そのコミットの本体を読み込む。前回の作業の再開時も最新版を取得し、版の変更があれば既存成果物への影響を確認して続きから進める。

* 配布元：`https://github.com/hallelujah097hallelujah-design/yamaken-seo-contents-member`
* 本体：ルートの `SKILL.md`、`references/`、`scripts/`、`assets/`、`agents/`
* 取得方法：GitHub APIで `main` の最新コミットSHAを取得し、同じSHAのアーカイブから上記本体を展開する。ファイル更新だけで次回実行に反映される。

1. **AIの実行環境**でPython 3.10以上が使えるかを先に確認する（`python3 --version`、なければ `python --version`、またはChatGPT側のPython実行機能）。未導入なら利用環境の正規の環境構築機能・標準パッケージ管理で導入し、再確認する。生徒のパソコンへのインストールを一律に求めない。コード実行機能自体がない場合はPythonを導入できたふりをせず、後述のGitHub連携で取得できる情報だけを扱い、未実行のチェックを明記する。端末設定・権限の変更は環境の承認手順に従う。必要なのはPython標準ライブラリであり、追加のpipパッケージや個人APIキーは不要。
2. このローダーの設置ディレクトリを基準に、同梱の取得スクリプトを確認したPythonで実行する。

   ```bash
   python3 "<ローダー設置ディレクトリ>/scripts/fetch_latest.py" --output-dir "<今回の作業ディレクトリ>/.yamaken-member-current"
   ```

3. 返されたJSONが `ok: true` であることを確認し、返された `skill_dir` の **`SKILL.md` 全文を読み、そこから指定される参照ファイルを工程に合わせて読む**。参照ファイル・文字数計測・チェックスクリプトの基準ディレクトリは、ローダーではなくこの `skill_dir` とする。同名の別スキルを再検索・再呼び出ししない。
4. 本体のバージョンと取得コミットを作業記録に残す。制作手順・本文・納品条件は取得した本体を正とする。Google検索結果はクラウドブラウザ最優先、通常の機能・接続上の理由で利用不可なら利用者のパソコンのシークレットウィンドウを可能な限りバックグラウンド操作する。本体の07 #2の切替条件・認証制限の扱いに従う。

## 取得できない場合

* PythonからGitHubへ接続できない場合でも、正規のGitHub連携が使えるなら、GitHubの `repos/hallelujah097hallelujah-design/yamaken-seo-contents-member/commits/main` で最新コミットSHAを取得し、`git/trees/<SHA>?recursive=1` で本体のファイル一覧を取得する。**同一SHAをrefに固定して** ルートのSKILL.mdとreferences・scripts・assets・agentsの全ファイルを取得・保存する。認証情報・秘密鍵は配布物や作業記録に保存しない。
* 連携で全文を取得できるがローカル保存やスクリプト実行ができない場合は、その制約を報告する。本体の文字数計測・最終チェックを実行済みとは扱わない。
* 取得失敗、参照ファイル不足、取得コミットの不一致の場合は、最新版を読み込んだふりをせず、旧版やモデルの記憶で制作を続けない。正規の代替取得もできなければ、その理由と未完了の作業を簡潔に伝えて停止する。ネットワーク制限を回避しない。

## 更新と配布

管理者がGitHubの本体を更新したら、次回実行時に更新後の内容を取得する。通常の制作ルール変更でローダーを再配布する必要はない。本体のファイル構成・取得先・ローダーの取得方法を変更した場合はローダーの更新が必要になることがある。本体のバージョンは本体の `SKILL.md` で管理する。

非公開のGitHubリポジトリは閲覧権限と認証が必要で、このローダーの認証なし取得は使えない。生徒のGitHub認証を不要にする運用では配布元を公開のまま維持する。公開中に取得・保存したZIPでも、本体を毎回取得するローダーなので、配布元を後から非公開に戻すと取得できなくなる。
